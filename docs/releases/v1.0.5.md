# EOS App v1.0.5

## 文件输入体验

- 可将文件拖入聊天区，在欢迎页和消息区也能添加附件，并显示拖入提示。
- 支持复制 Markdown、PDF、图片和多个文件后，在输入框按 Cmd+V / Ctrl+V 添加附件。
- 粘贴附件时保留原有文字，避免同一文件重复添加；普通文本继续正常粘贴。
- 修复普通文件被误判为不支持的图片，以及浏览器模式的附件内容传输问题。

## 下载与校验

下载页面：[eosaios.com/download](https://eosaios.com/download)。各平台安装包及便携归档同时发布在 GitHub Releases，SHA-256 校验值见 `SHA256SUMS.txt`。
