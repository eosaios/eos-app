# EOS App v1.0.8

- 优化聊天输入框的留白、附件布局和窄窗口下的工具栏间距，统一已发送图片附件的样式。
- 修复 macOS 26 应用列表中图标被灰色容器包围，以及启动和退出时图标样式短暂切换的问题。
- 网络短暂断开或流式响应意外中断时，最多自动重连 10 次，逐步增加等待间隔；等待期间可停止。
- 搜索改为独立进程执行，支持硬超时、取消和并发限额，搜索进程异常不再直接中断主内核。
- 增加搜索文件名、命中计数和分页续查，限制大文件、超长行与结果大小，修复中文工具结果截断引发的内核退出。
- 将本地内核连接中断与外网连接故障分开提示，便于判断问题来源。

安装包与 SHA-256 校验文件见本页下载附件。
