# EOS App v1.0.6

## 本地文件引用修复

- 修复 macOS 原生文件 URL 拖放未进入输入框的问题；通过原生文件事件识别落点并添加引用。
- Finder 复制文件后粘贴，保留原始路径及文件名；截图继续支持图片预览。
- Markdown、Word、Excel、PDF 等普通文件改为路径引用，由模型调用工具读取，避免把文档编码进模型附件导致 `HTTP 400: Param Incorrect`。
- 会话保存和重载后保留文件引用，继续对话时仍能通过原始路径访问文件。
- 图片继续使用图片附件通道；普通文件引用不再套用图片载荷大小限制。

此前失败消息中的附件不会自动重新发送。更新后请重新选择该文件，再发送消息。
