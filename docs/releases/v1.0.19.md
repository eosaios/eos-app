# EOS Agent v1.0.19

EOS 桌面工作台正式更名为 **EOS Agent**。新版程序与下载文件统一使用 `eos-agent`；原有账号、配置和项目记录继续使用。

- **灵活布局**：拖动调整文件树与内容区比例，重启后保留；提供标准、隐藏左侧列表、专注、文件布局及恢复默认入口。
- **自定义布局**：保存并命名当前布局，一键切换，支持重命名和删除；当前使用的预设或自定义布局高亮显示。手动调整后显示“已调整”。
- **macOS 录制整理**：在设置中查看录制历史，支持重命名、按大小排序、批量选择与删除；选择栏和删除确认展示所选视频总大小。删除将文件移到废纸篓。
- 优化分隔线反馈、图标菜单与鼠标悬浮提示。

提供 Windows x64、macOS Apple Silicon / Intel、Linux x64 / ARM64。系统安装要求和各平台能力以 README 为准。
