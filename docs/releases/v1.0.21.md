# EOS Agent v1.0.21

本次更新改善长文本的阅读、粘贴和编辑体验。

- 用户消息正文限制显示高度，长内容可在气泡内滚动查看，复制仍包含全文。
- 大段文本粘贴后以文本卡片显示，可一键还原到输入框继续编辑、滚动查看，也可补充说明后直接发送。
- 文本卡片仍是普通消息正文，不转换为文件或附件。
- 按当前所选模型的上下文 Token 上限检测输入；超限时保留草稿并禁止发送或 AI 优化表达，提示缩短内容或切换模型，切换模型后重新检测。
- 增加五个平台安装包的输入预算检查，验证超限内容不会写入会话或发给模型。

Token 数为估算值，完整请求中的历史、系统提示和附件仍占用模型上下文。

提供 Windows x64、macOS Apple Silicon / Intel、Linux x64 / ARM64。
