# EOS App 1.0.13

- New OpenAI connections use the Responses protocol by default. Existing connections and other providers keep their selected protocols.
- Model discovery, connection tests and model requests follow the proxy configured in EOS. Proxy changes apply to subsequent requests without restarting the app.
- Refine the Models page before the first provider is added, with distinct loading, error and empty states and improved layouts in narrow windows and both themes.

Available for macOS Apple Silicon and Intel, Windows x64, and Linux x64 and ARM64.
