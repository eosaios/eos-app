# EOS App 1.0.12

- Sign in with your EOS account using GitHub, Google or email. Return from the browser to the correct app and keep your session after restarting.
- Manage provider connections before adding models. Choose provider-specific plans and protocols, fetch available models, or add them manually.
- Confirm model deletion in a dialog. Conversations using a removed model select the same default as a new conversation.
- Fix duplicate companion pets after startup or updates.
- Download macOS, Windows and Linux installers from the EOS platform. Linux includes an installation script and browser-return registration.
- Keep the embedded browser available. Daily Chrome control remains unavailable until the matching extension is published.

Downloads: https://eosaios.com/products/app/
