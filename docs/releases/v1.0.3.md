## 改进

- **工作区规则折叠列表**：工作区默认以紧凑列表显示，点击展开后编辑和预览规则，收起仍保留未保存草稿。
- **工作区会话管理**：支持按工作区批量归档、恢复会话，已归档会话按工作区分组。
- **常规设置更完整**：可设置语言、默认文件打开位置、无项目目录，以及存储和读取目录。
- **对话与更新提示**：显示操作耗时，更新窗口支持格式化发布说明。
- **macOS 浏览器协作**：支持在隐藏标签页中导航和操作网页，改善切回窗口后的视口和焦点恢复。
- **macOS 桌面控制**：新增经用户授权的原生窗口控制，并提供持续可见的暂停、停止和撤销授权入口；应用兼容性取决于目标应用提供的辅助功能能力。
- **macOS 图标**：统一开发模式与安装包的图标尺寸和透明边距，修复 Dock 图标偏大的问题。
- **稳定性与凭据存储**：改善审批取消后的继续执行，支持可配置技能目录和本地加密凭据存储。

## 下载与校验

支持 Windows x64、macOS Intel / Apple Silicon、Linux x64 / ARM64。安装包内含签名内核，各文件 SHA-256 校验值见同页 `SHA256SUMS.txt`。

也可通过 [官方下载页](https://dl.eosaios.com) 或应用内检查更新获取新版本。
