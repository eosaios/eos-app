# EOS App v1.0.4

本版改进已有项目的启动与命令执行体验。

- **修复运行环境误报**：macOS 沙箱允许 Node.js、Rust 等运行时所需的基础系统信息读取，修复因权限误拦导致的内存初始化崩溃。
- **加载工具链环境**：Unix 命令使用用户登录 Shell，改善从桌面端启动时 PATH 不完整、已安装命令找不到的问题。
- **后台启动更易使用**：后台任务支持指定项目目录，持续保留日志和状态，方便检查开发服务、桌面开发命令与 watcher。
- **启动流程更直接**：定位目标项目后检查必要环境，使用项目原命令启动并验证就绪，减少重复探索、反复安装和换版本尝试。

本版保留工作区写入和网络策略边界。服务编译中或仅创建了进程时，不会因此认定已经就绪。

下载：[官网下载页面](https://eosaios.com/download)或本 Release 的安装包。各平台校验值见 `SHA256SUMS.txt`。
