# EOS App v1.0.7

## 输入框文件拖放修复

- 修复内置浏览器收起后，文件和图片拖进输入框仍弹回的问题。收起的浏览器退出原生视图树，展开时恢复页面，不再截获聊天输入。
- 附件接收区和“松开即可添加附件”提示限制在输入框内，不再覆盖整块聊天内容区。
- macOS 内置浏览器的新标签页和本地预览页支持拖入图片、PDF、HTML、文本等本地文件，多个文件分别打开标签。网站页面保留原生网页拖放行为。
- 修复 Markdown 和纯文本中文乱码；使用明确的 UTF-8 编码显示，刷新后保持正确编码。
- 保留 Finder 复制文件后粘贴、普通文档原始路径引用、图片预览及会话重载后的文件引用。
